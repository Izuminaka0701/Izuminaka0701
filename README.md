## 🚀 Featured Projects

### 1. Obfuscated Malware Detection using Machine Learning

**Role:** Team Lead | UEH Capstone Project

- Developed an ML pipeline for detecting obfuscated malware using static features.
- Extracted Opcode N-grams, Control Flow Graph (CFG) metrics, and PE API calls.
- Achieved 96.4% accuracy and 0.9912 AUC using XGBoost on 1,500 samples.
- Generated synthetic obfuscated samples using UPX and OLLVM.
- Developed a Flask dashboard with multi-model inference, ensemble voting, and SHAP explainability.

**Technologies:** Python, scikit-learn, XGBoost, PyTorch, angr, pefile, Flask.
